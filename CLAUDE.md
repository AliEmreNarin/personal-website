# CLAUDE.md

Custom Jekyll personal site for Ali Emre Narin (alinarin.site). No theme gem — every layout, include, and style lives in this repo.

## Layout of the repo

- `_config.yml` — site metadata, `nav:` items, permalinks, jekyll-scholar settings. `_config_preview.yml` overlays `baseurl: /preview` for the dev build.
- `_layouts/` — `default` (shell), `home` (avatar + bio + recent writing/reading), `page`, `post`, `bib` (one publication entry for jekyll-scholar).
- `_includes/` — `head`, `nav`, `footer`, `socials`, `cover` (one book cover), `book-grid`.
- `assets/css/main.css` — the whole design system. Tokens at the top; dark is default (`html[data-theme="dark"]`), light overrides under `:root[data-theme="light"]`. Accent is a single cool blue. Inter via Google Fonts.
- `assets/js/main.js` — theme toggle (localStorage) and the library's present/past tabs (`[data-tabs]` / `[data-pane]`).
- `index.md` (home), `_pages/{blog,publications,library,cv,404}.md`.
- `_posts/` — front matter: `categories: technical|non-technical`, `emoji:`, `featured:` (⭐). Blog index groups by `_data/blog_categories.yml`, then lists everything chronologically (Jamie Simon–style).
- `_bibliography/papers.bib` — publications; `_layouts/bib.html` renders entries; custom fields `pdf`, `arxiv`, `html`, `code`, `slides`.
- `_books/` — generated by `bin/sync_goodreads.py` (daily workflow). Never hand-edit; front matter keys: `title`, `author`, `isbn` (quoted!), `cover_goodreads`, `status` (Reading|Queued|Finished|Abandoned), `year` (shelf year), `stars`, `started`.
- `_data/socials.yml` — footer/home links; empty string hides a link.

## Workflows

- `deploy.yml` — push to `main` → build → `gh-pages` root (keeps `preview/`).
- `deploy-preview.yml` — push to `dev` → build with preview config → `gh-pages/preview/` → https://alinarin.site/preview/ (noindex, unlinked).
- `sync-goodreads.yml` — 06:00 UTC daily, commits new books to `main`.
- `prettier.yml` — `npx prettier . --check` (layouts/includes/\_books are ignored via `.prettierignore`).

## Local dev

```bash
export PATH="/opt/homebrew/opt/ruby/bin:$PATH"   # Homebrew Ruby; system Ruby is too old
bundle install && bundle exec jekyll serve
```

## Gotchas

- Quote ISBNs in YAML (`isbn: "0316556343"`) — unquoted leading-zero numbers parse as octal.
- Don't use Liquid range loops with variable bounds named like keywords (`(1..empty)` broke the old build).
- Goodreads `date_added` is not the read year; the sync writes `year:` from the `books-20XX` shelf and the library groups on it.
